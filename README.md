# Sequenciador de Peptídeos

Site (index.html) que lê espectros CID em .txt (m/z e intensidade), aplica filtro de sinal/ruído opcional e identifica íons y1, b1 e b2 de di e tripeptídeos, com base no script `di_e_tri_peptideo.py`. Com mais de um arquivo, mostra as combinações presentes em todos.

Tudo roda no navegador; para publicar, ative o GitHub Pages em Settings → Pages (branch main, pasta raiz).
